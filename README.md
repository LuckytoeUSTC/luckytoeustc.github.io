# Liqi Ding

Personal academic homepage, built with plain HTML and CSS.

- [Academic home](https://luckytoeustc.github.io/)
- [Personal](https://luckytoeustc.github.io/personal.html)
- [Statement of purpose — interactive map](https://luckytoeustc.github.io/sop-map.html)

## Files

`index.html`, `personal.html`, `style.css`, `assets/portrait.png`, and the self-contained `sop-map.html`. `.nojekyll` disables Jekyll processing.

## Deployment

GitHub Pages publishes the `main` branch from the repository root. Website changes go live after the Pages workflow succeeds.

The SOP map contains the v26 statement, bilingual structural analysis, and editorial notes. Local research materials and browser data are excluded from this repository.
